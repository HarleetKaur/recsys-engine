# Individual Project Reflection

**Project:** Large-Scale Personalized Recommendation Engine

During this project, I worked on executing, testing, and preparing a two-stage movie recommendation system for submission.

I ran the project in Google Colab using a T4 GPU, first with MovieLens latest-small and then with a 2,000-user subset of MovieLens 25M. I checked the pipeline outputs, investigated an API caching issue, and verified the corrected implementation with assistance.

I learned how two-tower retrieval, FAISS indexing, deep ranking models, and Redis caching work together in a recommendation system. I also gained experience interpreting NDCG and Recall metrics and understanding the difference between simulated A/B testing and real user experiments.

One important challenge was working with limited computing resources while keeping the experiments reproducible.

My practical contributions included executing and checking the experiments, organizing the GitHub repository, preparing the results for submission, and recording the working API demonstration. AI assistance was used for parts of the implementation, debugging, and documentation.

This project helped me understand both the technical architecture of recommendation systems and the importance of testing, reproducibility, and reporting limitations accurately.
